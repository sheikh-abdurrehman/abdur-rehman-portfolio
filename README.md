# Abdur Rehman | Shopify Developer Portfolio

A premium portfolio showcasing custom Shopify development, responsive storefronts, modern UI, and conversion-focused eCommerce solutions.

## Tech Stack

- React 19
- TypeScript
- TanStack Router
- Tailwind CSS v4
- Vite
- Radix UI
- Lucide Icons

## Features

- Premium responsive UI
- Shopify-focused portfolio
- Project showcase pages
- SEO-friendly structure
- Fast performance
- Mobile-first design
- Modern animations
